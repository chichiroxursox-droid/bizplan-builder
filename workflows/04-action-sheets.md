# 04 — Action sheets

Turn the plan's path into one-page, do-this-now sheets. Write to `output/action-sheets/`,
one file per quarter or phase, using `templates/action-sheet.md`.

## Rules for a good sheet
- **One page.** If it doesn't fit, it's not focused enough.
- **Trigger-based, not date-based.** "When you hit 20 jobs/week two weeks running, start
  hiring" beats "hire in Q2." Real businesses move at their own pace; triggers respect that.
- **Tied to the outcome.** Every action moves toward the Q1 north star. If one doesn't,
  cut it.
- **Names the metric to watch** for that phase — the single number that tells them whether
  to advance, hold, or fix.
- **Triggers and metrics inherit their tags from the plan** — the one-metric number on
  every sheet carries its `[VERIFIED]`/`[BENCHMARK]`/`[ASK]` tag.
- **Concrete and small.** "Post 3 before/after photos a week" not "improve marketing."

## Each sheet has
1. **Phase name + the trigger that starts it** ("Start when: …")
2. **The goal of this phase** (one line, in service of the outcome)
3. **3–6 concrete actions**
4. **The one metric to watch** and the number that means "advance to the next sheet"
5. **What to avoid** in this phase (the tempting wrong move)

When done, update `intake/STATE.md`, then go to `05-verify.md`.
